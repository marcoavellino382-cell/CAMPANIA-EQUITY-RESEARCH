# 📊 Campania Finance Dashboard

Benvenuto nel repository ufficiale dell'**Osservatorio Finanziario delle Aziende della Campania**, un progetto sviluppato per lo **Starting Finance Club** universitario. 

L'obiettivo di questo applicativo è monitorare in tempo reale le performance quantitative e i multipli fondamentali delle principali aziende quotate con un forte radicamento industriale e operativo nella Regione Campania.

🚀 **[CLICCA QUI PER APRIRE LA DASHBOARD INTERATTIVA]([)](https://campania-equity-research.streamlit.app/)**

---

## 🎯 Obiettivi del Progetto
* **Equity Research Locale:** Analizzare il tessuto imprenditoriale campano quotato su Euronext Growth Milan (EGM) e sul mercato principale.
* **Analisi Quantitativa:** Calcolare rendimenti storici normalizzati e volatilità degli asset territoriali.
* **Data Democratization:** Fornire ai membri dello Starting Finance Club uno strumento interattivo e accessibile per consultare dati finanziari live senza bisogno di terminali proprietari costosi.

## 🛠️ Stack Tecnologico Utilizzato
* **Python**: Core language per l'elaborazione dei dati.
* **Streamlit**: Framework per la creazione e il deploy della Web App interattiva.
* **Yahoo Finance API (`yfinance`)**: Estrazione dati finanziari e storici in tempo reale.
* **Pandas & NumPy**: Manipolazione dei dati, calcolo delle metriche e normalizzazione delle serie storiche.
